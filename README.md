# Luex
 
Cross-platform financial tracking application for desktop and Android with real-time cloud synchronization.
 
## Overview
 
Luex is a cross-platform financial tracking application designed to help users organize spending, monitor financial activity, and build more structured money-management habits.
 
Originally developed from a university practicum concept, the application was redesigned and expanded into a portfolio-ready cross-platform project using .NET MAUI, C#, XAML, and Firebase Firestore.
 
## Key Features
 
- Cross-platform desktop and Android application
- Structured financial tracking workflows
- Real-time cloud synchronization with Firebase Firestore
- XAML-based user interface built with .NET MAUI
- Persistent user financial data storage
- Multi-device data consistency
## Highlights
 
- Designed and developed a cross-platform financial tracking application using C# and .NET MAUI.
- Built real-time data synchronization using Firebase Firestore.
- Created structured workflows for tracking and organizing financial activity.
- Implemented a XAML-based user interface for desktop and Android experiences.
## Architecture
 
Luex follows a cross-platform application architecture:
 
- Application Framework: .NET MAUI
- Language: C#
- UI Layer: XAML
- Cloud Database: Firebase Firestore
- Supported Platforms: Desktop and Android
